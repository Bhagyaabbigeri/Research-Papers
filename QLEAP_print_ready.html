Track 3: Space
QLEAP: Quantum-Entangled Lattice with Entanglement-Aware AI Protocol
for Ultra-Secure Deep-Space Communication
Bhagyashree Reddy Department of Computer Science Engineering Visvesvaraya Technological University (VTU), Regional Centre Kalaburgi, India bhagyashreeabbigeri7@gmail.com

Problem: Classical deep-space links face 24-min latency, interception risk, and decoherence. Existing QKD systems (e.g., Micius) are limited to single LEO–ground hops. QLEAP introduces multi-hop orbital entanglement relays via Lagrange-point nodes and AI-driven Bell-state correction for provably secure planetary communication.

Objectives
  • Multi-hop entanglement chains: LEO → L1/L2 → Deep Space
  • AI Bell-state classifier → real-time decoherence correction
  • Quantum-secure key rate >10 Mbps via BB84 + E91
Proposed Solution
  • LQRNs at L1/L2 — gravitationally stable quantum relay nodes
  • ABSE: Transformer model → autonomous fidelity-based swap decisions
  • QPath: Dijkstra routing weighted by entanglement fidelity
Innovation / Novelty
First quantum memory nodes at Lagrange points — zero station-keeping
ABSE: First ML-based autonomous Bell-state timing engine in space
QPath: Fidelity as routing cost — paradigm shift in space networking
System Architecture — QLEAP Multi-Hop Orbital Relay Network
Methodology / Working
01Ground station generates Bell-state photon pairs via SPDC → uplinks to LEO satellite
02LEO relays photon to LQRN @ L1/L2 → stored in Rb atomic ensemble (coherence >1s)
03ABSE monitors fidelity → triggers purification if <0.95
04LQRN performs entanglement swapping → BB84+E91 delivers final quantum key
Applications
  • ISRO / DRDO: Quantum-secure strategic satellite communications
  • Planetary exploration: Secure telemetry + sub-ps clock sync for deep-space probes
Advantages Over Traditional Systems
  • Information-theoretic security — no computational assumptions
  • Eavesdropping physically detectable via Bell inequality violation
  • Dual-DOF encoding → 4× capacity with no extra spectrum
